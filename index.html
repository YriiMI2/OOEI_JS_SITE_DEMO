Що таке JavaScript?

Доповідач 1

JavaScript — мова програмування, яка додає вебсторінкам поведінку та інтерактивність. Вона працює в браузері, а також на серверах та в інших середовищах.

Коротка історія

Мову створив Брендан Айк у 1995 році для браузера Netscape. Спочатку вона називалася LiveScript, а згодом отримала назву JavaScript. Стандарт ECMAScript підтримує спільні правила розвитку мови.

Де застосовується

Інтерактивні сайти, вебзастосунки, сервери, мобільні й настільні програми, автоматизація та навчальні інструменти.

Три частини вебсторінки

HTMLСтруктура та зміст<button>Привіт</button>
CSSЗовнішній виглядbutton { color: gold; }
JavaScriptПоведінка й реакціїbutton.onclick = greet;

HTML описує елементи, CSS оформлює їх, а JavaScript реагує на дії та оновлює сторінку.

Доповідач 101

Змінні

Змінна — це підписана коробочка, у якій лежить значення. Створи кілька коробочок, спробуй змінити їхній вміст і подивись, чим let, const і var відрізняються.

=

Спробуй: const → потім «присвоїти» нове значення. Або створи ще раз змінну з тією ж назвою через let і через var.

Доповідач 102

Типи даних

Вісім «сортів» значень: сім примітивів і об’єкти. Клікни будь-який приклад або введи власне значення — JavaScript визначить його тип.

🔍 Аналізатор значень

Пиши числа, "рядки в лапках", true, null, [1,2], {"a":1}… або тицяй приклади вище.
Доповідач 103

Динамічна типізація

У JavaScript тип має значення, а не змінна. Одна й та сама змінна може бути то числом, то рядком, то масивом. А коли типи змішуються — JS мовчки перетворює їх.

Одна змінна — багато типів

Поклади в коробку x різні значення й дивись, як змінюється її «характер».
змінна x містить:
11
number
Змін типу: 0

Магія приведення типів

Впиши два значення й обери оператор. Результат часто дивує — і це нормально для JS.

Пиши власні значення: число — без лапок (5), рядок — у лапках ("5"), також true, null, undefined, [1,2], {"a":1}…

Доповідач 204

Масиви

Впорядкована колекція значень. Кожен елемент має номер — індекс, і лічба починається з нуля. Додавай, видаляй і сортуй.

довжина: 0
Дістати елемент за індексом:

Чому «сортувати за замовчуванням» ставить 100 перед 25? Бо воно порівнює елементи як рядки! Спробуй обидва варіанти.

Доповідач 205

Об’єкти

Об’єкт — це набір пар «ключ → значення». Тут ключі мають імена, а не номери. Значенням може бути що завгодно: число, масив, навіть функція (метод).

👤 user

Звернення до властивості — клікни рядок

Видали name і викличи метод — побачиш, що станеться, коли властивості немає. Спробуй «додати» вже наявний ключ — значення перезапишеться.

Програма сама обирає шлях. JS перевіряє умови зверху вниз і виконує першу, що виявилась правдивою; решту пропускає.

Доповідач 308

Взаємодія з веб-документом (DOM)

Браузер перетворює HTML на дерево об’єктів — DOM. JavaScript може знаходити вузли, створювати нові, міняти текст і стилі та видаляти їх. Справа — справжня мініатюрна сторінка; зліва — її живе дерево.

Доповідач 309

Події та їх обробка

Подія — це сигнал: «користувач клікнув», «натиснув клавішу», «ввів текст». Обробник — функція, яка чекає на сигнал і реагує. Підпишись на події й подивись, що приходить.

Підписка на події

Став і знімай галочки — обробники реально додаються та видаляються. Лічильник показує, скільки разів подія спрацювала.
Рухай мишею, клікай, крути колесо.
Для клавіш клікни сюди, щоб поле отримало фокус

Поля вводу та форми

Подія input спрацьовує на кожну літеру, change — коли поле втратило фокус. Натисни Enter у полі або кнопку — це вже подія keydown і click.
