Взаємодія з веб-документом (DOM)

DOM — об’єктна модель документа, деревоподібне представлення HTML. Браузер створює її під час розбору HTML і відкриває JavaScript через Web API. Глобальний об’єкт document дає змогу знаходити елементи, змінювати їх і створювати нові.

Як працює DOM

Браузер розбирає HTML і створює дерево вузлів. Елементи можуть містити вкладені елементи й текст. Об’єкт document надає JavaScript доступ до цієї структури через Web API.

window.document
document.documentElement
document.body

Зміна та створення

Знайди потрібний вузол, зміни його текст, класи або стилі. Нові вузли створюй через createElement і додавай методом append чи appendChild; непотрібні прибирай через remove.

const item = document.createElement('li')
item.textContent = 'Новий пункт'
list.append(item)
item.remove()

Події та їх обробка

Подія — це сигнал: «користувач клікнув», «натиснув клавішу», «ввів текст». Обробник — функція, яка чекає на сигнал і реагує. Підпишись на події й подивись, що приходить.

Підписка на події

Став і знімай галочки — обробники реально додаються та видаляються. Лічильник показує, скільки разів подія спрацювала.
Рухай мишею, клікай, крути колесо.
Для клавіш клікни сюди, щоб поле отримало фокус

Поля вводу та форми

Подія input спрацьовує на кожну літеру, change — коли поле втратило фокус. Натисни кнопку, щоб побачити обробку click.

Подія submit
